# 三步實作筆記：找字庫 → 疊字 → 修正風格

所有操作歸入以下三步。像素及效果參數依原圖估計，不把單一案例的數值當成通用預設。

## 1. 找字庫 · Find the font library

指定實際字體檔和字重，確認渲染器沒有換字體，查看排出的目標字。

例如「嬲」為 U+5B32，由「男・女・男」左右排列，不能混成「嫐」。Noto Sans CJK HK 是香港地區字體，不等於華康的「香港字庫」產品；使用者指定產品時不能靜默替換。

原字款缺字時，可選最接近且包含正確字形的字體，但要區分「接近原風格」與「使用原字體」。

香港字形來源例：

- [Noto CJK 官方專案](https://github.com/notofonts/noto-cjk)
- [Noto Sans 香港地區 OTF](https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/TraditionalChineseHK)

下載前核對官方目前的檔案與授權。技能包不附第三方字體或使用者原始圖片。

## 2. 疊字 · Overlay

**量度**：使用 glyph ink bounds，按實際筆畫的可見邊界定位。先完成基本位置及尺寸，保留可調整字層；精細風格留在第三步。

**清除錯字**：包括錯字的描邊與陰影，同時保護鄰字。平滑暗背景可從周邊乾淨區域重建；紋理或照片需要符合內容的修補。單一實色矩形通常會露餡。

**實際合成**：將第一步取得的字形作透明圖層、字體輪廓或文字層覆到正確位置。不是貼上字庫截圖的背景，也不是請生成模型猜一個字。

macOS 可用 CoreText 取得字形輪廓、CoreGraphics 疊字；其他環境使用符合工具規則的字體排版及合成工具，不依賴某位使用者的路徑。

## 3. 修正風格 · Fix the styling

選旁邊兩三個同色、同大小的字，比較下表。只選一款名為 Bold 的字體，不能保證配合原標題。

| 項目 | 比較與調整 |
| --- | --- |
| 高度與基線 | 白色筆畫頂部及底部，不是包含陰影的外框 |
| 寬度與字距 | 字面及左右空隙；複雜字不能只套相同字號 |
| 字重 | 橫豎筆畫厚度及內部留白 |
| 形態 | 壓窄、拉長、斜切、圓角或方角，避免扭壞結構 |
| 描邊與陰影 | 顏色、厚度、轉角、位移、透明度及柔度 |
| 填色與質感 | 純白或偏灰、漸層、粗糙及壓縮痕跡 |

**描邊順序**：先畫陰影及深色外描邊，再重新填上白色字面。部分 API 的 stroke 是置中描邊；先填白再描黑會侵蝕細筆畫，使字過瘦甚至發黑。

**逐步增加字重**：小幅擴張白色輪廓，或回用第一步選定字庫的適合字重更新字層，再做風格匹配。每次加粗後核對內孔及交接點，不能把複雜字內部全填滿。

**匹配畫質**：新字體可能比原截圖太銳利。僅對新字及必要效果輕微柔化、降採樣或匹配紋理；例如 macOS 可用 CoreImage 局部處理。不要模糊整張圖來掩飾修補。

**融合乾淨邊界**：錯字須已清除，否則 feather 會讓舊筆畫透出。陰影及模糊要留足取樣邊界，避免被硬切。

**檢查及交付**：所有柔化及融合完成後，檢查最終圖，不要拿中間圖的像素檢查代替最終驗收。先看原尺寸是否融入，再放大核對結構，最後確認其他內容保留，輸出完整新檔。

「嬲」案例說明：字庫提供正確「男・女・男」結構；直接疊字仍被使用者指出風格不符；因此第三步必須調整字重、邊緣、描邊及背景。該案例最後候選版本未獲明確確認為完全匹配，不能當作效果保證。
