# GOtrip review profile

Load only when the focal newsroom is GOtrip / GOtrip.hk. This is GOtrip business taxonomy, not a template for other BUs. Shared writing, case-analysis, media, chart and QA rules remain in the common contracts.

## Core programmes and subject taxonomy

Use these exact Core labels: 達人帶路、北上CheckList、為食出走、好動旅人、假期策劃師、旅遊封神榜、其他. All formats retain their programme identity, including single images and feeds whose carousel status is still unknown. 「手動Carosuel」 is not a GOtrip Core pillar.

Recognise the approved name with or without `#`, including heading forms such as `【假期策劃師】`. Match Latin aliases case-insensitively as complete names: `GOtrip_a` matches, `GOtrip_ab` does not. Match the complete Chinese programme name. Caption text can establish programme membership without becoming evidence for Reel performance.

Apply classification in this order:

1. Any of `#旅遊封神榜`, `旅遊封神榜`, `#GOtrip_a`, `GOtrip_a` → 旅遊封神榜, including posts also naming another programme.
2. Otherwise an identified one of the five programme names → its original programme, regardless of format or missing `#`.
3. If several ordinary programme names appear, use the explicit heading identity; ambiguous membership remains a documented question rather than an arbitrary list-order choice.
4. Remaining GOtrip posts → 其他. Its notes identify actual subjects and formats, with representative links, so the editor can see what is included.

Count each post once in the Core inventory. Compare these programmes internally across periods/formats. Classify general subjects independently from the reviewed content, with at most six report-level groups; the programme names are not a mandatory subject list and competitor posts keep their own identity.
