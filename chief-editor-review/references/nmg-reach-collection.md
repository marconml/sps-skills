## Collection success contract

1. Reuse supplied NMG CSVs when they cover the approved owner pages, platform and the three complete review months. Otherwise open the dashboard using the available browser tools and existing user session. This user-authorized report workflow includes attempting read-only export/download; it does not authorize publishing or account changes.
2. Read the actual visible controls before choosing the owner page, FB/IG, date window and post report. Export post-level CSV/Excel including Reach. Export HD whole-page output and OS **all posts**, with no health-only filter; perform the two OS classifications locally. Inspect active filters, dates and platform before download. Button names and menu paths beyond the entry URL remain UI-dependent; use observed controls rather than guessing endpoints or reproducing private APIs.
3. If login, SSO or an internal-network restriction appears, ask the user to complete access in their browser; retain the pending tab when a handoff is needed. If the site returns 403, record that access blocker and ask for a working authorized environment or the matching export. A 403 response is not evidence that the report is empty. Preserve the available interaction package and clearly mark owner reach pending until access or the export is supplied.
4. Save untouched exports in source-exports and record owner page, platform, date window, observed UI filters, original filename, unique post count and collection time. Verify completion and parseability of the downloaded file. No credentials, session tokens or signed download URLs in source, reports or Git.

Treat these as recognition examples, not guaranteed headers. Reach is the intended field; impressions, video views and paid reach are distinct.
